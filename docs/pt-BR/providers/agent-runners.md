# Executores de agentes (Agent Runners)

## O que é um executor de agentes?

Um executor de agentes (*Agent Runner*) é o componente do AstrBot responsável por executar os recursos de agentes e gerenciar fluxos de trabalho relacionados à IA.

O AstrBot inclui um executor de agentes integrado e robusto. Também é possível conectar serviços de terceiros, como Dify, Coze, Alibaba Cloud Bailian e DeerFlow, ou desenvolver seu próprio executor.

Mesmo que você já tenha um provedor de modelos capaz de processar solicitações individuais, ainda será necessária uma camada de execução para lidar com conversas de várias etapas, chamadas de ferramentas e orquestração. Essa é exatamente a função de um executor de agentes.

Para saber mais, consulte [Uso · Modo de execução de agentes](/pt-BR/use/agent-runner).
