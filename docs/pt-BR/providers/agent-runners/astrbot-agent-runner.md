# Executor de agentes integrado

Por padrão, o AstrBot usa o executor de agentes integrado como executor principal. Não é necessário configurar nada para aproveitar os recursos desse executor.

![Imagem](https://files.astrbot.app/docs/source/images/astrbot-agent-runner/image.png)

Com o executor integrado, você pode usar o [servidor MCP](/pt-BR/use/mcp), a [base de conhecimento](/pt-BR/use/knowledge-base), a [pesquisa na Web](/pt-BR/use/websearch) e os recursos de persona do AstrBot.
