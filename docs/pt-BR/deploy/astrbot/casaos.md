# Implantar o AstrBot no CasaOS

## Instalar o CasaOS

```bash
curl -fsSL https://get.casaos.io | sudo bash
```

## Adicionar a fonte de aplicativos CasaOS-AppStore-Play

![image](https://files.astrbot.app/docs/source/images/casaos/image.png)

Clique em `More Apps` e informe o endereço abaixo:

```txt
https://play.cuse.eu.org/Cp0204-AppStore-Play.zip
```

Adicione a fonte e aguarde a conclusão do processo.

Se sua rede estiver na China continental, pesquise e adicione primeiro o `dkTurbo`; caso contrário, talvez não seja possível baixar a imagem do AstrBot.

![image](https://files.astrbot.app/docs/source/images/casaos/image-1.png)

Pesquise por `Astrbot` para localizar o AstrBot.

![image](https://files.astrbot.app/docs/source/images/casaos/image-2.png)

Clique no ícone do aplicativo (não no botão de instalação). Em seguida, passe o cursor sobre o botão `Install` e selecione **Custom Install**.

![image](https://files.astrbot.app/docs/source/images/casaos/image-3.png)

Na seção **Network**, selecione `host`.

![image](https://files.astrbot.app/docs/source/images/casaos/image-4.png)

Depois, clique em `Install` para iniciar a instalação.

Quando o processo terminar, o aplicativo AstrBot aparecerá na tela principal. Clique nele para abrir o painel.
