# Perguntas frequentes — AstrBot Brasil

## Esta edição é oficial?

Não. AstrBot Brasil é uma edição comunitária brasileira adaptada e mantida por @mkbraion.

## O código original foi criado por mkbraion?

Não. @mkbraion é responsável pela edição brasileira, localização, documentação e melhorias desta distribuição.

## Qual é a licença?

O código principal declara AGPL-3.0-or-later. Existem também componentes de terceiros com licença própria, incluindo a licença MIT preservada em `dashboard/LICENSE`.

## Posso trocar o idioma?

Sim. `pt-BR` é o padrão desta edição, mas os outros idiomas preservados continuam disponíveis.

## Posso usar Docker?

Sim. O repositório mantém os arquivos de Docker/Compose do projeto-base.

## Onde reporto problemas desta edição?

Use a aba Issues do repositório `mkbraion/AstrBot-Brasil` e, de preferência, o template brasileiro de bug.
